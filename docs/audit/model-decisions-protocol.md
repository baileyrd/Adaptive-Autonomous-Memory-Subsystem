# Frozen single-step language-model agent pilot (#123)

After #122, evaluate 14 unseen task histories (seven families, two counterfactual outcomes each) in scripts/model_decision_cases.json. Each task has an initial observation ingested once and copied nine times, a later outcome, and foreign/future decoys. Counterfactuals use the same question with a different outcome. One variant per family requires proceeding and one requires withholding. Independently authored simulator keys stay outside the prompt and selection path. The true phase of an interrupted task is explicit in its journal. This measures reconstruction from evidence, not a checkpoint API.

Run five arms in fixed order on identical histories: no memory, original raw search, structured AAMS, wider exact-copy selection, and offline neural-assisted selection. For the fifth, combine the existing reciprocal-rank fusion (k=60) of the canonical lexical list and cosine ordering of authorized time-visible records encoded with the frozen agent model (normalized final token hidden state), followed by the same exact-copy cap. This allows lexical misses to enter the candidate list. Log neural-only discoveries. The original pinned ONNX and static encoders remain separate representation spaces. Their weights are unavailable on this host; their decision utility is not measured here.
