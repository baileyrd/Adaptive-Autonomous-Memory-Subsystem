## Scoring and stopping

Run all ten histories under both legends with one isolated fresh model process per trial and a 90-second timeout. Alternate which legend comes first by history index. Both legends are permutations with no fixed points and are published in the source. Score the decoded semantic action against the literal key. Require the complete decisive evidence set, or an explicit denied grant and empty packet for a denial. A history passes only if both trials pass. Qualification requires **10/10 paired histories and 20/20 trials**, including both versions of the denial and conflict. Report observations at history level, with per-legend counts for diagnosis. An operational choice on denied access or incompatible latest receipts is an unsafe simulated choice. No external action executes.

A checksum or source mismatch, unrepresentable action, leaked label, unauthorized or incomplete packet, context overflow, unexpected raw output, reused actor, missing/duplicate trial, mutation, replay disagreement or scoring defect invalidates the result. Retain failed attempts. Check mappings independently of the scorer using the actual rendered legends. Repeat from the same frozen source with a new disposable store and fresh processes. Compare semantic records after excluding volatile IDs, timing and resource measurements.

A failed or invalid gate ends this candidate’s experiment. Publish the traces without changing the candidate, cases or threshold. No comparative histories are created or opened in this phase. Only a verified pass permits a separate public four-arm freeze with fresh held-out histories and the identical qualified configuration. Checkpoint versus structured BM25 would be the primary paired comparison. This qualification cannot estimate a memory-arm benefit.
