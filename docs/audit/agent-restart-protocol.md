# Scoped checkpoint-assisted action control (#124)

Base: main `798a79e` after #131. This is one new, disposable **rule-agent control**, not a language-model or production checkpoint implementation. O5 / FR-009 / H6 and #115 require actual task continuity outcomes; #130/#131 measured deterministic restore/head resolution. This slice adds failed-attempt state, first actions/consequences, four memory arms and a separate capability diagnostic. No existing experiment is revised. The #129 model's 14/14 neural abstentions remain negative evidence.

## Agent and interpretation boundary

Use `restart-observation-policy-v1`, exact instruction and implementation in `scripts/restart_agent_policy.py`, Python >=3.11. The actor reads only a JSON packet with instruction, task ID, goal, designated executor and source citations. It receives no split, family, oracle, simulator world, expected action, tool credentials or mutable conversation state. Its fixed policy reads the latest complete executor observation, abstains on unresolved conflict or missing evidence, resolves constraints first, repairs an outstanding failed verification, otherwise performs the first unfinished step in prepare/verify/publish order. It reports action, supporting IDs and interpreted state. The subprocess has no tool interface; filesystem/network sandboxing of a hostile actor is not claimed. This rule policy is an author-written control, not a learned/general agent.

The pinned #129 Qwen GGUF/runtime are absent. A download attempt returned CONNECT 403; the managed environment rejected adding its host to the published network policy. An optional llama-cpp-python installation also failed to build. **Language-model recovery is NOT RUN**, and successful rule calibration cannot establish model capacity. No substitution of synthetic responses for model output is allowed.

## Experimental checkpoint contract

`disposable-agent-checkpoint-v1` is an evaluation-only sidecar, not an extension of persistent checkpoint authority or canonical semantics. The existing amended ADR-0010 remains the product-design boundary. It contains task identity and goal, scope, builder producer, recorded/effective times, expiry, interpreted completed work, complementary pending work, failed verification attempts, unresolved approval constraints and exact supporting IDs/digests/provenance/times. Goal, identity, grant, scope, cutoffs, designated executor and registered envelope digest are **trusted synthetic host assertions**. State certificates are simulator executor observations, not proof of real-world completion. Completed/pending/failed/constraint fields are **builder interpretations** of those observations, never independent evidence.

Prepare a checkpoint from scope/time-eligible observations available at interruption (both cutoffs day 4), without labels. Expiry is day 8 except the expired family, day 5; resume is day 6. A preparer writes the sidecars and canonical fixture database, then exits. A registered digest means the host recognizes the proposal, not that it attests completion. Restore checks the current grant before opening any sidecar, then task/goal/scope/digest/schema/producer/cutoffs/expiry. Reauthorize every source, its digest/provenance and both claim/request time bounds; verify interpretations and pending complement against the original source. Reject the entire claim on any mismatch. Only independently verified **original source bytes** reach the actor. Public rejected state is empty; detailed offline statuses do not enter the actor packet.

No new checkpoint tables, migrations, native/MCP API, persistent authority, automatic checkpoint write/refresh or generated canonical promotion. The preparer and trusted grants are fixtures; host authentication, principal ACL service, concurrent/transactional revocation and durable lifecycle enforcement remain separate reviews.

## Preregistration and inputs

Before any scoring, commit all implementation, protocol and tests; publish its SHA and `restart_agent_freeze.json` input/label/source hashes on #124. Then execute unchanged. Freeze 4 calibration tasks (partial/failure counterfactual pairs), 16 design and 16 held-out tasks (eight families, two variants each). Source IDs/scopes/producers/locators are disjoint between splits and use a new namespace/seed. Cases share grammar and are author-visible; they are not unseen task mechanisms. Each pair renames identities and changes one semantic state component; no claim of representative workload frequency. Unauthorized variants both require denial, rather than manufacturing an action-changing access-denial pair.

Families: partial completion; unresolved prior failure versus no outstanding failure; approval constraint; superseded prior instructions (old opposite constraint followed by current instruction); delayed observation recorded after interruption; expired checkpoint with independently readable sources; current access denied; foreign checkpoint envelope with readable local sources. Every history includes journal chatter, foreign evidence, a recorded-after-cutoff decoy and an effective-after-cutoff decoy. Frozen literal action keys are separate from the actor and are not computed by its policy. They are checked in the parent only. The action consequence simulator uses latent fixture state, separately from the agent's claimed state.

## Matched arms and restart

1. **No memory:** task/instruction only, empty history.
2. **Transcript:** recent raw eligible journal records, descending recorded time then ID, bounded without answer-aware filtering.
3. **Structured:** unchanged native scoped BM25 `CognitiveMemory.recall`, query = goal + `completed failed_attempts constraints restart_state`, up to 100 candidates/65,536 packet bytes before final packing.
4. **Checkpoint-assisted:** restore source references; combine with post-interruption executor observations from the same structured candidate path, then remaining candidates. On rejection perform an explicitly authorized read-only structured fallback. Do not refresh the checkpoint or pass rejected content. This builds on #131's fallback result; it does not compare against a bare rejected checkpoint or direct canonical-head oracle.

Each memory arm has access to the same scope/time-eligible underlying observations and an identical final limit of eight citations / 8,192 JSON context bytes. Deduplicate by evidence ID; stop at the first item that would overflow. All actor packets, including task/instruction, must fit 12,288 bytes. This is a byte-budgeted rule control; token costs are not measured. The asymmetry of transcript recency, lexical discovery and checkpoint reference selection is the treatment and must be reported, not hidden as equal retrieval interfaces.

Each arm reopens the same store through SQLite `mode=ro` in a separate interpreter after preparation has exited. **Every task decision starts another fresh interpreter**, with one stdin packet and no state from previous decisions. Limit actor execution to 10 seconds and each arm subprocess to 180 seconds; timeout/nonzero exit invalidates execution, never becomes an agent abstention. No external tools, neural dependencies, downloads, writes or model calls in the actor or default CI.

## Full-evidence calibration and failed diagnostic interpretation

Run only the four separate calibration tasks with all decisive observations included (older-to-newer order; eight-record cap leaves all calibration state certificates visible). Publish their packets, outputs and evidence coverage. Pass requires **4/4 supported correct actions** and all required evidence visible. If evidence is absent the diagnostic is invalid; if visible but misread the diagnostic fails. In either case still publish the frozen four-arm comparison, but mark task-utility interpretation **inconclusive due to diagnostic failure**, do not tune the policy/prompt on held-out answers and do not attribute failure to memory alone. Even a pass validates only this rule control, never the unavailable #129 model.

## Frozen scoring, attribution and uncertainty

Score the first action only: verify, publish, repair, resolve or abstain. Simulated consequence is advanced, correct denial, stalled, unsafe publication, or wasted work. Record correct actions **with support**, correct guesses lacking required support, invented progress, repeated completed work, repeated unresolved failures, lost active constraints in returned state, unavailable active constraints, incorrect abstentions and unsupported non-abstaining actions separately. Two held-out access denials must not be described as resumptions. Correct required denials need no protected citation. Require the current certificate as conservative support even when an older identical certificate would happen to justify the same action; report that limitation.

For each non-correct case assign the earliest failed stage: evidence unavailable to that arm, missed by retrieval, excluded from final context, or presented but misinterpreted. Record candidate IDs, full actor packets, interpreted states, outputs, expected actions and consequences so correct guesses remain auditable. Retrieval coverage denominator excludes required denials. A memory-disabled arm's missing observations are unavailability, not a BM25 failure. Calibration is excluded from paired efficacy scores.

Report paired held-out correctness differences for each memory arm versus no-memory and versus structured recall. Bootstrap 2,000 equally weighted whole-family units (eight families, both counterfactual variants kept together), seed 0, percentile order statistics 50/1950. Also publish paired gains/regressions and both-members-correct counts. The interval is descriptive for eight shared synthetic mechanisms; it cannot establish generalization. No positive checkpoint-benefit claim unless its supported correctness exceeds structured recall with a positive lower paired bound and zero extra safety failures. Preserve neutral and negative comparisons.

## Four scorecards and invalidation

Publish separate memory correctness/safety, cognitive outcomes, retrieval effectiveness and operating-cost records. Validate every delivered source against canonical bytes, digest, source, scope and both request time bounds. Any unauthorized/cross-scope/time-ineligible disclosure, use of an expired/rejected interpretation as evidence, partial invalid restore, invented citation, budget excess or file mutation invalidates the run. Incorrect agent actions are cognitive outcomes, not silently converted into storage failures. Checkpoint rejection followed by independently authorized canonical evidence is not expired-cache disclosure.

Record complete preparer and per-reader physical file manifests plus the #131 portable logical database digest. Compare physical bytes within a run, logical content across environments; record Python, SQLite and platform explicitly. Emit actor/preparer/worker PIDs, elapsed decision time including actor startup, worker CPU, total actor-child CPU, worker RSS and maximum individual actor RSS separately. Include DB/sidecar size. These are Linux sequential fixture costs, not matched deployment gates or combined/concurrent RSS. Cold model load, inference/token costs, persistent authority, real task consequences, model replacement and production utility remain **unmeasured**.
