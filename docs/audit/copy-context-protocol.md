## Reproduction and single hypothesis

First reproduce every historical decision against the frozen #118 trace. For its three copied-report episodes, inspect both memory arms' eight delivered citations and the complete visible pool. Test the **same agent** with that full pool and classify whether the later failure is available canonically, dropped before the context boundary, or misinterpreted after delivery. Full-pool diagnostic runs may exceed the agent budget and are root-cause probes, not intervention quality results. Never change the historical trace or its labels.

Hypothesis: known copied reports consume context slots before later contrary evidence can reach the agent. A single **offline** selector will scan the existing structured BM25 ranking before the final context cap, retaining one citation per `(source_actor, source_locator, digest, observed_at)` group, preserving rank order. All fields must come from canonically revalidated citations. Same-time opposing reports have different digests and must both survive; different declared sources must remain separate even with identical text. This key identifies declared exact-copy groups, **not genuine source independence** or paraphrased-copy detection. No adverse-label preference, time reranking, agent change, oracle access or learned scorer is added.

Compare unchanged raw BM25 search, unchanged structured BM25/guarded recall, and structured recall with known-copy selection. The control inspects at most 100 canonical citations / 65,536 packet bytes before giving the agent the same eight-citation / 8,192 serialized-byte context. This increased internal candidate inspection is explicit and its cost is measured. If the candidate window itself truncates, report it. No product serving path, provenance semantics, authority or routing default changes.

## Fresh source-disjoint design and held-out cases

Freeze a new generator/recipe and generated case hash **before implementing/measuring the correction**. Seed 1192026. Seven mechanism families, two design and eight held-out episodes per family, two decisions each: 14 design episodes / 28 decisions and 56 held-out episodes / 112 decisions per arm. Held-out copy counts/times vary from the design examples. All evidence IDs, topics, scopes and declared source origins are disjoint between splits and from #118; verify this rather than assuming it from names. The mechanism categories are deliberately shared controls, so this is a source-held-out test of one hypothesis, not seven unseen reasoning mechanisms or real-world generalization.

Required families: copied positives plus a later failure; copied positives with no later failure; genuinely distinct declared support sources; current versus historical changed states; same-time opposing reports sharing a declared origin; relabelled copies whose origin cannot be identified from metadata; recovery after copied older negative reports. Private/future decoys and instruction-like payloads appear in every episode. The relabelled-source family is an expected limitation: the selector may not infer independence or discard distinct source identities using hidden generator labels. Recovery/clean cases detect an intervention that merely favors negative evidence or increases abstention.

The fixed #118 rule agent, instruction and simulator oracle remain unchanged. Gold world states and `later_ids` are scorer-only; the selector receives only authorized canonical citation rows. Source labels and simulator truth are not externally attested. Before the first aggregate run, freeze implementation/test hashes in an execution manifest as a second commit, record both preregistration SHAs and post them to #119. Execution refuses source/data hash mismatches. Changes required to fix defects must be documented before rerun; no hidden held-out tuning.

## Outcomes, safety and uncertainty

Report actual decisions, unsafe proceed count/rate, task success, abstentions, wrong stops, time-visible later-report coverage, contradiction-pair coverage, used evidence, declared-copy groups and clean/recovery regressions. `later_ids` coverage is a retrieval diagnostic, not a substitute for outcome correctness. Run paired bootstrap over whole mechanism families (2,000 resamples, seed 0); seven family units, not 112 independent reasoning mechanisms. Show outcome deltas and sample limits; no significance claim from small synthetic intervals alone. Publish all negative cases, including outcomes that improve safety only through abstention.

Every delivered and inspected candidate citation must pass the original scope/time/digest/provenance validator. Validate scope/time **before** grouping; hidden private/future records must not alter visible outputs. Check canonical database digests before/after. No canonical mutation or automatic promotion is allowed. The rule parser's inert instruction handling says nothing about a model's prompt-injection resistance. Task checkpoints, LLM reasoning, transfer, neural utility and real-world learning remain unmeasured.

Use fresh separate preparer/decision processes per arm, identical source workloads and limits, five timing passes per request, 60-second preparation and 120-second per-arm execution bounds. Costs are independent observations, never quality-admission gates. Retain exact Git/source/data/trace hashes, chronology and commands; source files and historical reports are not rewritten. Default CI remains synthetic and requires no model downloads or optional inference dependency.

The deliverable is a root-cause classification, targeted offline control, fresh per-arm decision evidence and a recommendation. Any production context-selection change requires a separate bounded proposal and current-head review/CI/protection checks.
