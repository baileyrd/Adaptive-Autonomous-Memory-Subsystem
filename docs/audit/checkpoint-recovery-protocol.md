# #124 preregistered disposable interruption/recovery experiment

Status: source-disjoint fixture and design frozen before evaluation implementation/scoring. Authority: [#124 execution specification](https://github.com/baileyrd/Adaptive-Autonomous-Memory-Subsystem/issues/124#issuecomment-7142418062). [ADR-0010](../adr/0010-disposable-task-checkpoints.md) is proposed, not approval for product persistence.

## Question, arms and independent truth

Compare (1) transcript-only deterministic reconstruction, (2) validated checkpoint reconstruction, (3) a canonical-state deterministic control. Use identical task grants, requested valid/recorded times, task manifests and final 8,192-byte state/citation budgets. The transcript arm receives the last eight authorized, time-visible journal records; it must not treat an agent note as a completion certificate. The checkpoint arm restores a compact claim by reauthorizing all referenced evidence. The canonical control fetches the host's current head certificates directly, without seeing the expected action; it separates evidence/presentation completeness from downstream model capability. Internal exact-reference lookup differs from bounded journal replay and is reported, not called a pure model comparison.

One fixed deterministic action function acts on a reconstructed state: resolve the first blocking constraint, otherwise execute the first not-completed step, otherwise finish; unavailable state means abstain. Independent expected actions derive from latent simulator progress/constraints and current access, **not** checkpoint claims or citations. A forged checkpoint can disagree with the simulator and the canonical completion event. The checkpoint/restore code never receives the latent world or expected action. This is a synthetic contract/mechanism test, not AI reasoning or long-term learning.

The #129 pinned small-model result remains unchanged: delivering decisive context did not ensure correct actions. The current workspace has neither its model bytes nor optional llama-cpp runtime. Actual model-driven reconstruction and model replacement are explicitly NOT RUN, not replaced by fake model responses. A new interpreter/reader tests process/serialization portability only. Do not call it model replacement or claim H6 validated for AI agents.

## Frozen data

Seed 1242026; twelve families, two design and four held-out cases each: 24 design + 48 held-out interruption scenarios per arm. Families: valid ready state, transcript truncation, fabricated progress, changed constraints/stale revision, expiry, supersession, checkpoint revocation, access revocation, cross-scope reference, contradictory current states, future reference, wrong digest. Work identifiers, task/scopes, executor/source identities and checkpoint IDs are opaque and source-disjoint across splits and previous #117/#119/#123 fixtures. Check this before execution. Shared synthetic grammar/mechanisms and author-visible fixtures limit independence claims; cases within a family are clustered variants.

Every case has immutable task-state evidence, an untrusted fabricated-progress note, a private record, a future record and instruction-like journal text. The simulator's true completed work/constraints are separate from the cached claim. A simulated trusted host supplies current task heads and reader/proposer registry grants. Cache expiry/revocation/supersession does not revoke underlying canonical evidence, so a transcript/control may resume where the checkpoint must abstain. Stale/invalid checkpoint denial is a safety result, not automatically successful task recovery.

A preparer writes temporary evidence and a sidecar, then exits before a separate decision worker reopens them. Hash the entire canonical logical database before/after. All arms use fresh disposable stores, same data and request bounds. Host authorization precedes reads; foreign/nonexistent/revoked cases have identical public-unavailable shape. Each accepted checkpoint reference is rechecked by scoped canonical lookup and digest/provenance/time. Ready results must reproduce the certificate's complete/pending work and current constraints; no model claim can promote itself.

## Outcomes, budgets and uncertainty

Score actual next resumed action against the independent simulator oracle; report correct resumption, repeated completed work, invented completed progress, lost constraints, abstention, lifecycle status, citation validity and any denied/expired-state disclosure. Rejection is not counted as correct resumption unless abstention is the actual oracle action (e.g. access denied). Report ready/eligible cases and invalid/lifecycle cases separately to prevent favorable denominators. Contradictory but canonically valid states must remain unresolved even when the hidden simulator knows a true state. Unsafe disclosure/mutation invalidates a run; do not filter failures from results.

Pair identical task IDs and bootstrap whole scenario families (2,000 resamples, seed 0); twelve family units per split, not 48 independent mechanisms. Report descriptive intervals and failed comparisons without a positive-benefit requirement. The deterministic control is not the scoring oracle: it reads the same canonical state heads under the same grant, and can still reject contradictory evidence.

Final context ceiling: 8,192 bytes, at most eight checkpoint evidence refs / transcript records. Three timing passes per request do not create additional task samples. Sequential arms, 60-second preparer and 120-second worker limits. Record process IDs, CPU/wall p50/p95, process peak RSS, sidecar/database bytes and all input/source/trace hashes. Costs never veto offline task reporting. No model downloads, optional inference dependencies, network calls, default-CI model installs or product writes.

Freeze a separate execution source/test manifest before the first aggregate run, after this data/design preregistration commit. Reject changed source/data/old-artifact hashes. Preserve earlier artifacts and record any correction as a protocol amendment before rerun, never held-out tuning. Publish proposed contract, source-disjointness proof, per-arm decisions, negative cases and recommendations with exact-head CI. Product checkpoint persistence/API remains unimplemented pending contract review and a separate bounded implementation.
