# v0.9 CPU cost protocol

Use the existing checksum-pinned BAAI BGE small v1.5 export, CLS pooling, 512-token truncation and the pinned optional Python dependencies. Compare the baseline one-thread session against two and four intra-op threads and the extended graph optimization setting, changing one setting at a time. The runner executes arms on the same host in fresh processes. Tokenization, input feeds and normalization are unchanged. Batching is excluded because the interactive call accepts one query.

Before measurement, register the same-model vector tolerance of maximum absolute distance 0.00001 and identical top-three IDs. The resource gates are no more than 5 ms additional end-to-end p95 versus guarded and at most twice guarded peak RSS. A candidate must satisfy both workloads. Use the first eight passages of each of the first three SQuAD articles with one original question per passage, independently on the pinned train and dev files. Run one warmup through recall and ten timed repetitions. This is a bounded cost preflight, with no retrieval-quality conclusion.

The report includes load time/RSS, first post-index query pass, median/p95 wall and process CPU, encode phases and peak RSS across build and serve. A separate preparation process produces a reduced workload so full-dataset parsing does not inflate the child process memory denominator. The first query pass follows index construction and is not a cold session inference measurement.

## Published quantized alternatives

A separate optional workflow resolves and verifies versioned Xenova ONNX exports. The initial identification run matched each download to its upstream LFS object SHA-256 or Git object ID. Subsequent runs require the checked-in revision and SHA-256 for both model and tokenizer in `scripts/onnx_variant_pins.json`. The BGE export uses CLS pooling. The smaller MiniLM L3 export uses mean pooling with disabled tokenizer padding. Both are 384-dimensional. The representation spec includes the exact bytes, model, revision and pooling, so comparable dimensions alone cannot mix their index spaces.

Use a fresh directory with `python scripts/prepare_onnx_variant.py minilm-l3-q8 model`, then pass `--model model --variant model/manifest.json` to the benchmark. Model and tokenizer files are downloaded only by the explicit evaluation helper. None are copied into this repository or distributed with AAMS.
