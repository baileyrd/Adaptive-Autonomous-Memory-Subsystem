# #117 preregistered decision replay pilot

Status: protocol frozen before the first aggregate pilot execution. Parent: [#117](https://github.com/baileyrd/Adaptive-Autonomous-Memory-Subsystem/issues/117), [#105](https://github.com/baileyrd/Adaptive-Autonomous-Memory-Subsystem/issues/105), original [H1–H8](../design/v0.1.0/docs/08-research-evaluation.md). Uses the [quality-first research contract](../acceptance/v1.0-research.md). No live model, learned routing, neural activation or product changes.

## Question and limits

Does current structured AAMS change actual decisions relative to equally bounded raw search and no historical memory, on an independently scored synthetic environment? The agent is a fixed, transparent rule policy, **not an LLM**. Results measure a bounded mechanism pilot; model-agent reasoning benefit remains NOT MEASURED. No model API or encoder is introduced. No positive result or significance threshold is required to publish the pilot.

This operationalizes the first workstream-C pilot, not the complete broader task-level plan. It uses four design and four held-out scenario mechanisms, three episodes per mechanism, two decisions per episode: 24 episodes / 48 paired decisions per arm, including 12 episodes / 24 decisions in each split. The original plan's 12 *different* development and 12 confirmation families is not fulfilled: here the independent resampling units are only **four families per split**. Episodes within a family are correlated variants. The family split is frozen without tuning against pilot outcomes, but all scenarios are author-visible and generated by the same grammar. It is not independent real-world or blinded model evidence.

## Frozen actors and information

- No-memory: no prior context; the same rule agent generally abstains because the current request supplies no hidden environmental facts. Its zero/low completion rate is a trivial information-absence control, not a meaningful intelligence effect.
- Raw search: canonical scope/time-visible source reports ranked with existing BM25, without typed belief interpretation.
- Structured: current default `CognitiveMemory.recall`, scoped BM25/guarded, no semantic provider. Citation normalization and ceilings are shared across arms. Current host-authorized fixture belief revisions can surface support/refutation; replay never writes beliefs.

Both memory arms use the same query, eligible source history, eight-citation ceiling, 8,192 serialized context bytes, and identical agent instruction/policy. Raw search uses AAMS canonical authorization/citation visibility to avoid intentionally unsafe access, but ranks source evidence rather than formations/beliefs. The ranking implementation is intentionally strong and may match structured recall; parity or regression must be reported. Deduplication by evidence identity and byte truncation apply before agent execution. Five repetitions measure timing, not independent task samples; the first repetition's warm/cold mix is disclosed. A preparer gets 60 seconds and a fresh decision worker 120 seconds per arm, with sequential workers and no network/model dependencies.

The agent sees only topic, required checks, fixed instruction and bounded citation rows. It has no world state, family/split, expected action or label access. It chooses `proceed` if all required conditions are clear, `stop` on a blocked condition, and `abstain` for missing/conflicting information; reports are selected by observation time, not repetition count. A pure simulator oracle separately computes the physically appropriate action from latent environmental state at the task's valid time. Reports can be wrong, absent, copied, delayed or injected. Labels are actual simulator computations, not retrospectively fabricated successes or retrieval coverage labels. This remains synthetic truth, not externally verified observations.

Each episode includes inaccessible private, future-dated and instruction-like decoys. Evidence, formations and explicit inferred/contested revisions are seeded through canonical APIs by the simulated host. The preparer injects a fixture-only clock for revision recording; the decision process runs after that preparer exits and has no clock patch or write grant. Storage/process restart is tested. It must never be described as implemented task checkpoint recovery, independent-agent state reconstruction or model replacement.

## Measurements and validity

Score actual actions against simulator state. `success` requires the correct proceed/stop action; abstaining avoids a reckless action but does not complete the task. Report success, historical action correctness, exact retrospective condition-state accuracy, abstention, wrong non-abstaining action rate (not probabilistic calibration), unsupported action assertions, canonical citation precision, contradiction handling and known-failure repeat rate. A valid citation can support an incorrect world conclusion; source fidelity and world truth are separate. No citations yields null precision rather than a perfect score. The repeat metric counts a later decision to attempt an action with a simulator-recorded prior failure; it is not proof of reduced real-world error recurrence or policy learning.

Record which evidence the decision uses and compare the action with the same agent receiving empty historical context. A changed action is evidence of context sensitivity, not proof of sophisticated reasoning. Paired bootstrap deltas against raw search use whole families, 2,000 resamples and seed 0, separately per split. Four-family intervals are descriptive; repeated timings and within-family variants do not enlarge independent N. No selection or tuning after the first aggregate run.

Validate **every delivered citation**, not only cited evidence, against canonical scoped ID, digest, provenance, preview and observed/recorded times. Unavailable citations, tampering, unsafe actions outside the allowed vocabulary, nondeterministic decisions or memory mutations invalidate the entire run. Hash the canonical database before/after decision replay. Scope/time/provenance are safety checks, not negotiable quality/cost tradeoffs. Instruction-like records are inert for this JSON rule parser; model instruction-following safety is NOT MEASURED.

Publish four separate records: (1) safety validation and memory immutability, (2) decision outcome summaries, (3) retrieval effectiveness explicitly NOT SCORED (no relevance gold), (4) process RSS, database bytes, request p50/p95 and CPU. Costs never suppress task measurements. The request timing excludes scoring/validation and includes a first request; cold-start tails, concurrency and deployment readiness are NOT MEASURED. Missing checkpoint/sharing/consolidation-transfer/neural/model arms remain explicitly unimplemented or unexecuted.

## Reproducibility

`cognitive_task_preregistration.json` freezes recipe, generator, agent and evaluator source hashes plus the generated case hash. CLI execution refuses changed inputs/source, and records the executed Git SHA and hashes. Changes needed to fix measurement defects require a documented protocol revision before rerun, never hidden retuning. The initial protocol/source commit precedes the first aggregate pilot invocation; its SHA and results are recorded in the report and issue.

```sh
python -m pip install -e '.[mcp]' ruff==0.14.6
python scripts/evaluate_cognitive_tasks.py > pilot.json
python -m unittest discover -s tests -p test_cognitive_tasks.py -v
ruff format --check src tests scripts
ruff check src tests scripts
python -m compileall -q src tests scripts
python -m unittest discover -s tests -v
python -m aams.demo
```

An invalid/failed run exits 3 with an explicit status; it must not be published as an efficiency/quality success. CI uses only synthetic fixtures and stdlib dependencies. See the accompanying pilot report for actual results, counterexamples and remaining unmeasured #117 outcomes.

Add those checks/counters and tampering regressions, then refreeze the evaluator before rerun. The recipe, generated cases, instruction, decision agent and oracle are unchanged. This is a measurement-validation amendment, not policy tuning. Preserve the first run's source SHA and compare decisions on rerun; any change in actions would need investigation.
